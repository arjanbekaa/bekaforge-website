> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a simplified, publish-ready Beka Forge website that presents DGS 3.0.0 and AI Providers as available, AI Extension as coming soon, and uses GitHub for editable public URLs and issue reports.

**Architecture:** Keep the existing static HTML/CSS/JavaScript site and its dirty in-place product restructuring. Add a same-origin JSON configuration with whitelisted runtime overrides and fail-safe defaults, GitHub Issue Forms for reports, then update the root pages and product documentation around the approved release-state matrix. Validate with Node's built-in test runner, a static link/config validator, and real browser checks.

**Tech Stack:** Static HTML5, CSS, browser JavaScript, JSON, GitHub Pages, GitHub Issue Forms, Node.js built-in `node:test`.

## Global Constraints

- Dialogue Graph System is available as version 3.0.0 at $24.99.
- AI Providers for Unity is published, free, and links to package `384482`.
- Dialogue Graph AI Extension is coming soon and has no store URL or public technical-doc navigation.
- Never place passwords, API keys, provider credentials, GitHub tokens, webhook secrets, or private report data in public files.
- Preserve all pre-existing dirty-worktree changes; never reset, clean, or restore the checkout wholesale.
- Keep the site build-free and compatible with GitHub Pages at `bekaforge.com`.
- Reuse supplied product covers and real editor screenshots; do not generate replacement marketing art.
- Every behavior change follows RED, GREEN, REFACTOR using Node's built-in test runner.

async function htmlFiles(directory) {
  const root = new URL(`../${directory}/`, import.meta.url);
  const results = [];
  async function walk(url, prefix) {
    for (const entry of await readdir(url, { withFileTypes: true })) {
      const relative = `${prefix}${entry.name}`;
      if (entry.isDirectory()) await walk(new URL(`${entry.name}/`, url), `${relative}/`);
      else if (entry.name.endsWith(".html")) results.push(`${directory}/${relative}`);
    }
  }
  await walk(root, "");
  return results;
}

- [ ] **Step 3: Add the public JSON and whitelisted loader**

The JSON contains `publisher`, `support`, and the three product records only. Update `textresources.js` so it:

```js
const configUrl = new URL("site-config.json", document.currentScript.src).href;
const allowedProductKeys = ["status", "price", "version", "assetStoreUrl", "youtubeUrl", "docsPath"];
const urlKeys = new Set(["assetStoreUrl", "youtubeUrl", "docsPath", "githubUrl", "emailUrl", "reportIssueUrl"]);

function isSafeUrl(value, allowEmpty) {
  if (value === "") return allowEmpty;
  if (/^(https?:|mailto:)/i.test(value)) return true;
  return !/^[a-z][a-z0-9+.-]*:/i.test(value) && !value.startsWith("//");
}

function mergePublicConfig(config) {
  if (!config || Array.isArray(config) || typeof config !== "object") return;
  const copyStrings = (target, source, keys, optionalEmptyKeys = new Set()) => {
    if (!source || Array.isArray(source) || typeof source !== "object") return;
    keys.forEach((key) => {
      if (typeof source[key] !== "string") return;
      const value = source[key].trim();
      if (urlKeys.has(key) && !isSafeUrl(value, optionalEmptyKeys.has(key))) return;
      if (value || optionalEmptyKeys.has(key)) target[key] = value;
    });
  };
  copyStrings(resources.publisher, config.publisher, ["assetStoreUrl", "youtubeUrl", "githubUrl"]);
  copyStrings(resources.support, config.support, ["emailUrl", "reportIssueUrl"]);
  Object.keys(resources.products).forEach((productKey) => {
    copyStrings(
      resources.products[productKey],
      config.products && config.products[productKey],
      allowedProductKeys,
      new Set(["assetStoreUrl", "youtubeUrl"])
    );
  });
}

async function loadPublicConfig() {
  try {
    const response = await fetch(configUrl, { cache: "no-cache" });
    if (!response.ok) throw new Error(`Config request failed: ${response.status}`);
    mergePublicConfig(await response.json());
  } catch (error) {
    console.info("Beka Forge public config fallback active.");
  }
  applyTextResources(document);
  return resources;
}

window.BekaForgeConfigReady = loadPublicConfig();
```

The full implementation must reject arrays/objects for scalar fields, ignore unknown keys, accept only `http:`, `https:`, `mailto:`, same-origin relative paths, or an empty optional URL, and never remove defaults when a value is invalid.
