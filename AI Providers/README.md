# AI Providers

Public product folder for AI Providers / AI Connector.

## Contents

- `index.html` is the public provider product/documentation page.
- `assets/images/` contains provider screenshots and current placeholder overview graphics.
- `brand/` contains the temporary provider mark plus future final product logo/icon assets.
- `favicon/` contains the favicon set used by this product page.

## Notes

- Keep this folder focused on provider setup, transport, configuration, and testing concerns.
- Do not present AI Providers as the same product as the AI Extension.
- Replace placeholder visuals in `assets/images/` and `brand/` when final provider screenshots and branding assets are available.
