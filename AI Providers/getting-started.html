Getting Started

Set up a reusable provider profile and make your first request. These instructions cover the 2.2.0 release candidate; the Store update is not yet published.

Requirements

Unity 2022.3 LTS or newer. AI Providers is a standalone .unitypackage with no dependency on DGS or AI Extension. Provider accounts, usage charges, native subscription tools, and local models are supplied separately.

Create and test a profile

  1. Import the standalone .unitypackage using Assets > Import Package > Custom Package.
  2. Open Tools > Beka Forge > AI Providers > Settings.
  3. Choose Add Profile, select the provider type, name it, and confirm creation.
  4. For an API profile, configure the endpoint and model, enter your key in the local masked field, then run Test connection.
  5. Use Fetch Models where supported. Search the scrollable list by any part of the model ID, then select a model. Model availability depends on the provider and account.

Editor subscription profiles

Codex and Claude Code profiles use separately installed official local tools. Connect Subscription uses the tool's own sign-in flow. These profiles are editor-only and do not silently fall back to API billing. Use an HTTP/API profile in shipped players.

Send a prompt from an editor workflow

using BekaForge.AIProviders.Runtime;
using UnityEngine;

var request = LlmPromptRequest.CreateUserOnly("Hello!");
if (!AiProvidersService.TryBuildExecutionSnapshot(provider, request, out var snapshot, out var error))
{
    Debug.LogError(error);
    return;
}
var result = await AiProvidersService.SendPromptAsync(snapshot, cancellationToken);
if (result.Success) Debug.Log(result.ResponseText);
else Debug.LogError(result.Error);

Runtime workflows

Use BeginPromptCoroutine(...).Coroutine from a MonoBehaviour. TrySendPrompt is a blocking compatibility API and should not run on a runtime UI thread.
