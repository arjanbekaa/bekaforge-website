Key product boundaries

Standalone transport layer

The package is dependency-free and can be reused by tools outside Dialogue Graph System.

Provider assets over hardcoded switches

Each provider subclass owns its request shape and response parsing instead of relying on one monolithic service switch.

Local secrets, shared config

Provider assets store configuration and remain shareable. Supported protected credential storage keeps API keys local; never put keys in shared assets, screenshots, or a shipped player.

Runtime caveat

TrySendPrompt is obsolete because it blocks. Use the cancellable coroutine path at runtime, or build a snapshot on the main thread and await the async service in editor workflows.
