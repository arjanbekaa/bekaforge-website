Public API

Public namespaces start with BekaForge.AIProviders.Runtime.

Common types

  • LlmProviderDefinitionBase: provider configuration and request building.
  • LlmPromptRequest: typed single-turn user request with an optional system prompt.
  • LlmChatRequest and LlmMessage: ordered chat content.
  • AiProvidersService: snapshot creation, asynchronous HTTP requests, coroutine and streaming adapters.
  • PromptResult: success, response text, diagnostic and optional token usage.

Minimal HTTP/API editor request

using BekaForge.AIProviders.Runtime;
using UnityEngine;

var request = LlmPromptRequest.CreateUserOnly("Hello!");
if (!AiProvidersService.TryBuildExecutionSnapshot(provider, request, out var snapshot, out var error))
{
    Debug.LogError(error);
    return;
}
var result = await AiProvidersService.SendPromptAsync(snapshot, cancellationToken);
if (result.Success) Debug.Log(result.ResponseText);
else Debug.LogError(result.Error);

The caller supplies a configured provider and cancellation token. Handle snapshot validation errors before sending. Build snapshots on Unity's main thread.
