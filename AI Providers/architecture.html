Architecture

A standalone provider layer shared by editor tools and runtime callers.

Request flow

Build a provider execution snapshot on Unity's main thread. The async service sends the HTTP request and returns normalized text, diagnostics and token usage where reported. Coroutine adapters support MonoBehaviour callers; streaming adapters deliver incremental text.

Ownership

  • Provider assets own shared endpoint, model, transport and reliability settings.
  • Provider implementations own request construction and response extraction.
  • The request service owns execution, retries, timeouts and cancellation.
  • Protected local credential storage keeps API keys out of shared assets.
  • Codex and Claude Code subscription transports are editor-only and use local tool authentication.

Package boundary

Runtime and editor assemblies are AiProviders.Runtime and AiProviders.Editor; public namespaces use BekaForge.AIProviders. No DGS assembly is needed.
