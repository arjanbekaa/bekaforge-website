Settings and Keys

Share profile configuration while keeping credentials local.

Provider assets

Profiles store endpoint, model, transport and reliability settings. API keys are never serialized into those assets.

Protected local credentials

Supported platforms use protected OS-backed credential storage. Windows uses DPAPI and macOS uses Keychain. Linux protected credential persistence is unavailable. Legacy plaintext PlayerPrefs values are migrated on read and removed after successful migration. Check the storage status shown in the editor.

Editor preferences

Prompt defaults, selected profile and other local editor preferences are stored separately. Subscription credentials remain owned by the installed native tool.

Online documentation links

The Documentation and Website buttons fetch the public site-config.json when clicked. Edit products.aiProviders.docsPath and products.aiProviders.websiteUrl on GitHub to change their destinations. Valid links are cached locally; offline or invalid responses retain the last valid links, or bundled defaults when no cache exists. The request times out after five seconds and sends no provider keys, prompts or project contents. Drawing the UI makes no configuration request.

Sharing safely

Share profile configuration rather than secrets. Do not embed an API key in source, screenshots, exported assets or a shipped player.
