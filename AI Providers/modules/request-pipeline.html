Request Pipeline

Use asynchronous or coroutine requests for responsive editor and runtime workflows.

Build, then send

Build the execution snapshot on the main thread using TryBuildExecutionSnapshot. Await SendPromptAsync for HTTP/API editor work. Use BeginPromptCoroutine in MonoBehaviours and the streaming adapters for incremental responses.

Reliability

Profiles expose timeout, retry count and base retry delay. Transient failures use exponential backoff with jitter. A provider's positive Retry-After interval is honored without truncating it to 60 seconds; long waits remain cancellable. Authentication and validation failures fail without retrying.

Response and usage

PromptResult exposes success, extracted response text, error, diagnostics and token usage where the provider reports it. Structured JSON and streaming support depend on the selected provider.

Subscription requests

Local subscription transports use native editor tools, not HTTP/API credentials. They never silently switch to API billing. Cancellation and editor lifecycle handling stop owned processes; native platform behavior needs separate validation.
