Provider Assets

Profiles are ScriptableObject assets containing reusable connection settings.

API and local-model providers

OpenAI, OpenAI Compatible, DeepSeek, Gemini, Ollama and Custom JSON. Use OpenAI Compatible for compatible services; Custom JSON supports explicit request and extraction configuration.

Editor subscription providers

Codex and Claude Code connect through user-installed native tools and their existing accounts. Availability and model lists depend on that account. Subscription profiles are not runtime transports.

Shared and local state

Assets hold display names, endpoint settings, models and reliability settings. Keys remain in supported local protected storage. Ordinary edits preserve asset GUIDs; Duplicate creates a new asset without copying credentials or connection-test results.

Selecting models

Fetched model IDs appear in a searchable, alphabetized list. IDs containing slashes stay intact. Long IDs have full tooltips. Filtering does not change the profile; choose a result and confirm, or cancel. Keep a custom model by editing it manually.
