Troubleshooting

Start with the local diagnostic message, endpoint and selected model.

API connections

  • 401: re-enter the local key and check its provider permissions.
  • 404: check the base URL and endpoint.
  • 429: check quota; retries honor the provider's Retry-After interval.
  • Ollama offline: start the local service and install the selected model.
  • Unknown model: refresh the provider model list or enter the exact model ID manually.

Subscription connections

Install the official local tool, connect its subscription, and refresh status. Confirm account entitlement and tool version. These connections are editor-only and never fall back silently to API billing.

Credentials

Check the editor's protected storage status. Linux protected persistence is unavailable; native macOS behavior requires platform acceptance. Duplicated profiles need their own credentials.

Documentation links offline

Buttons use the last valid cached URL registry, or bundled defaults if the registry cannot be fetched. The destination page itself still requires an Internet connection.
