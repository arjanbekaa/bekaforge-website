Troubleshooting

Most AI Extension issues fall into four buckets: compile gating, provider setup, routing ambiguity, and plan/apply safety constraints.

Compile-time visibility issues

If the floating AI Assistant panel or settings panels never appear, confirm the required define BEKA_FORGE_DGS_AI_EXTENSION_READY_V3 is present. Much of the editor-side feature surface is intentionally gated by that symbol.

Provider-backed requests fail

  • Verify AI Providers is installed and compiling.
  • Verify a provider asset is selected and its local API key is set on the current machine.
  • For OpenAI-compatible endpoints, verify the root base URL plus the expected chat endpoint combination.

Wrong workflow opens

Routing is heuristic by design. If a broad authoring request opens a tool route or a narrow rewrite falls into a plan flow, reduce ambiguity: select an anchor node, simplify the instruction, or use more explicit phrasing such as rewrite, continue branch, or suggest choices.

Plan apply is blocked

Blocked or partial apply usually means one of three things: safety limits were exceeded, symbolic references could not be resolved, or the current graph/editor capability validator rejected some operations.

Current practical constraint

If a request is too broad or too ambiguous, the safest fix is usually to narrow the instruction, select a clearer anchor, or break the work into smaller passes before applying anything to the graph.
