Public API

The cleanest public-facing concepts are the bridge contract, the command enum, the shared settings asset, and the plan DTO. Many preview windows and pipeline helpers are architecturally important but are not the strongest long-term extension surface.

Settings asset load behavior

DialogAISettings.LoadFromResources() loads the first matching asset named DialogAISettings from any Resources folder. The source code warns when multiple matches exist.

What not to over-promise

Preview window classes, route detector heuristics, prompt builders, and apply pipeline internals matter for maintainers, but they are not the strongest public compatibility surface. The public docs here intentionally keep the API emphasis on the concepts other systems actually integrate with.
