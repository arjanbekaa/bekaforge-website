# Dialogue Graph AI Extension

Public product folder for the Dialog System AI Extension product area.

## Contents

- `index.html` is the public AI Extension product/documentation page.
- `assets/images/` contains public AI Extension screenshots used by the website.
- `brand/` contains the AI Extension product icon and any future product-specific logo assets.
- `favicon/` contains the favicon set used by this product page.

## Notes

- Keep this folder focused on the optional AI authoring add-on, not the provider backend.
- Do not add an Asset Store URL here unless a public listing exists.
- If deeper public docs are moved into this folder later, update `../assets/data/textresources.js` first.
