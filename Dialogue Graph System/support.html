Support

Start with the documented setup and troubleshooting checks. Use public GitHub reports for reproducible website or documentation problems and email for private purchase details.

Before reporting a problem

  1. Confirm you are using Dialogue Graph System version 4.0.0.
  2. Read Installation and Troubleshooting.
  3. Capture the Unity version, exact Console error, reproduction steps, and the smallest relevant scene or graph setup.
  4. Remove API keys, invoices, personal data, and proprietary project content from anything posted publicly.
