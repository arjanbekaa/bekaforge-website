FAQ

Is this system runtime-only or does it include authoring tools?

It includes both. Runtime, editor, and optional module code are split into product folders and assemblies inside the DGS 4.0 bundle.

Can I start dialogues without using dialogID?

Yes. DialogManager.StartDialog(DialogGraph graph) starts directly from an asset reference.

Does the system support branching?

Yes. A choice follows its authored link, and DGS records the selected branch path for transcript reconstruction when the conversation is started through a registered dialog ID.

Can I trigger gameplay events during dialogue?

Yes. Use action nodes together with DialogActionRunner and, when needed, IActionHandler.

Does it support a history or backlog UI?

Yes. DialogueHistory and DialogueHistoryView provide that feature.

Is there AI generation support?

The AI Extension is included in the DGS 4.0 bundle; AI Providers is a separate optional package required only for AI authoring. Core graph authoring and runtime do not require a provider. Check the dedicated AI authoring guide for the supported provider setup.

Can I replace the included UI?

Yes. DGS separates dialogue flow from its runtime UI controller and manager. Keep the public runtime view and choice contracts intact or supply an adapter for your replacement. Theme artwork/layout authoring is covered by the included UI Themes tools.

Can I author contextual Banter or graph sound without AI?

Yes. Banter and the Sound Sequencer are included modules with their own authoring and runtime setup. Start with Set up Banter or Set up Walla sound.
