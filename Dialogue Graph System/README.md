# Dialogue Graph System

Public product folder for Dialogue Graph System.

## Contents

- `index.html` and the linked HTML pages are the public DGS documentation set.
- `assets/images/` contains DGS documentation screenshots used inline with the relevant sections.
- `brand/` contains DGS product imagery, product icon files, and legacy exported branding assets.
- `favicon/` contains the favicon set used by DGS public pages.

## Notes

- Keep DGS as the flagship product area.
- When adding new public screenshots, prefer `assets/images/` for documentation images and `brand/` for product-card or store-style branding images.
- Update shared public links in `../assets/data/textresources.js` if DGS public paths change.
