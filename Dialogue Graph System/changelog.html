Dialogue Graph System 3.0.0

Version 3.0 brings the authoring, validation, localization, runtime, and showcase workflow together as one focused release.

Authoring workspace

  • Unified launcher and graph browser for creating, organizing, and opening dialogue assets.
  • Graph authoring for dialogue, choices, actions, conditions, variables, graph jumps, outcomes, and grouped flows.
  • Character, action, variable, environment, context, localization, import/export, and settings tools available from the same workspace.

Validation and layout

  • Graph validation helps identify structural issues before runtime.
  • Layout formatting and minimap support improve navigation through larger branching graphs.

Runtime and presentation

  • Runtime dialogue, choices, typewriter text, audio, portraits, history, and settings overlays.
  • Theme and UI settings for text, choices, input, audio, and runtime presentation.

Included showcase

The demo presents three focused journeys: a product tour, a branching shop-gate conversation, and a control-room action flow.

Separate products: AI Providers for Unity is available independently. The optional Dialogue Graph AI Extension is coming soon and is not part of DGS 3.0.0.
